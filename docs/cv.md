# Official CV PDF

Upload the approved PDF to `public/cv.pdf` on `feature/digital-portal-stage1`.
Both English and Chinese CV navigation items, including Home and mobile navigation,
use `/cv.pdf`. A native browser navigation opens the PDF viewer; its download
control saves the document. Browser preferences may instead download PDFs.

Until a file with a PDF header is present, CV stays visible but has no destination
and is marked unavailable. No sample PDF or HTML/Markdown CV is provided.
Rebuild after adding or replacing the PDF: availability is checked during static
export. No other content or navigation edits are required.
